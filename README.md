Single Price Grid Component Solution
This is a clean, responsive, and modern solution to the Single Price Grid Component challenge on Frontend Mentor.

Links
Solution URL: https://github.com/veon321/Single-price-grid-component

Live Site URL: https://veon321.github.io/Single-price-grid-component/

Built with
Semantic HTML5 markup (including <article> container and structural lists)

CSS Custom Properties (Variables) for strict design-guide color matching

Flexbox layout for structural alignment and layout axis swapping (row to column)

Modern CSS Math Functions (clamp()) for fluid typography and responsive padding

Google Fonts (Karla)

Features
Nested Flexbox Layout: Uses a multi-level Flexbox approach where the main container controls the vertical stacking, and a nested .card-bottom wrapper seamlessly handles the split columns on desktop.

Fluid & Scalable Design: Internal section paddings and major font sizes scale fluidly using clamp(), ensuring the card looks elegant on medium tablet screens before it breaks.

Responsive Axis Swapping: A clean media query swaps the direction of the bottom panel to flex-direction: column at 600px, instantly collapsing the desktop grid into a highly readable mobile layout.

Enhanced Typography Contrast: Colors and text opacities in the subscription and features lists are finely balanced to ensure web accessibility (WCAG) while perfectly matching the original design assets.

Centered Viewport Presentation: The component is centered both vertically and horizontally via min-height: 100vh on the body, keeping the layout grounded and preventing content cutting on small screens.
